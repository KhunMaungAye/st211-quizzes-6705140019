# Assert Lab

This folder is a small assertion and test-style practice lab. It focuses on checking the behavior of a simple `ShoppingCart` implementation and on demonstrating how Python collections and floating-point comparisons can be expressed clearly in tests.

The examples in this folder cover:

- adding items and tracking count and total price;
- verifying list, dict, and set equality with `pytest` assertions;
- checking float comparisons using `pytest.approx()` instead of relying on exact equality.
